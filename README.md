# Unusuals Network corporate website

Static corporate website source for **Unusuals Network**, legal owner of the **Unusu@ls** product brand.

## Deployment target

- Platform: Cloudflare Pages
- Production hostname: `www.unusuals.worldofchampionsnetwork.com.ng`
- Framework: none (static HTML/CSS/JS)
- Build command: none
- Build output directory: repository root

## Safety boundaries

- No PDS changes.
- No database or backend.
- No analytics or marketing trackers in V1.
- No TIN, bank information, property evidence, or other private KYC documents are published.
- Owner has approved use of the CAC-submitted business address: `Amuyo Area, Offa, Kwara State, Nigeria`.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080/`.

## Visual identity

The home page uses the owner-approved Unusu@ls / Unusuals Network artwork as the full hero background. The original uploaded artwork is web-optimized at `assets/images/unusuals-network-hero.webp`; responsive CSS protects the central wordmark on desktop and mobile.
